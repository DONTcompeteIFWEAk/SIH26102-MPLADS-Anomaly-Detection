AI / ML Architecture

Dual-Layer Hybrid Framework: 3-Model ML Ensemble + Statutory Rules

04 / 11
HYBRID DECISION FORMULATION: Risk Score = (0.55 × ML Ensemble Score) + (0.45 × CAG Statutory Rules Score)

1. Isolation Forest (45%)

  • 300 orthogonal decision trees isolating points with shallow partition paths.
  • Unsupervised isolation across allocation logs, median disparities, and delay.
  • Sub-sample: 512, contamination: 0.05.
  • Detects non-linear multi-variable anomalies without normal distribution assumptions.

2. Profile-Deduplicated LOF (35%)

  • Solves the zero-distance Euclidean collapse on repetitive civil works (handpumps).
  • Groups identical feature profiles into canonical representations before KNN.
  • Computes Local Reachability Density against true non-duplicate neighbors.
  • Prevents standard repetitive works from distorting density metrics.

3. PCA Reconstruction Error (20%)

  • Projects high-dimensional vectors onto principal variance eigenvectors.
  • Calculates L2 reconstruction residual norm upon inverse projection.
  • Flags erratic expenditure spikes that break underlying scheme correlations.
  • Provides mathematical guarantee of global linear consistency.
